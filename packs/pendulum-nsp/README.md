# pendulum-nsp (placeholder)

First content pack. Placeholder line loosely modeled on Pendulum Nature
Spirits; names only. **All art here is original placeholder art** generated by
`npm run gen:art` (colored blobs). Real sprites only ever arrive via local
pack import, never in this repo.

The evolution chart is a stand-in for testing the format, not an accurate
Pendulum chart. Step 3 replaces it with the full roster.
