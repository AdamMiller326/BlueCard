# Blue Card

Fan-made Digimon roguelike deckbuilder prototype (Godot 4.7). Design docs in `docs/`.

- Open the project in Godot 4.7 and run the main scene (the nursery).
- Tests: `GODOT=/path/to/godot ./run_tests.sh`

Free, unmonetized fan project. Digimon names and concepts belong to Bandai. No Bandai art or audio is included.
