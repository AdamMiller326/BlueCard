# Digital Monster V Pet

Free, fan-made check-in virtual pet (PWA). Pendulum Color roster with Digital Monster X gameplay.
Design: [`docs/design.md`](docs/design.md). Project rules: [`CLAUDE.md`](CLAUDE.md).

```
npm install
npm run dev         # local dev server
npm test            # Vitest
npm run build       # typecheck + production build
npm run lint:packs  # validate packs/ with the in-app validator
npm run gen:art     # regenerate placeholder sprites + icons
```

Requires Node ≥ 22.18 (the CLI scripts run TypeScript directly).

Playtesting: open the **Debug** panel to speed up the clock (up to 3600×) or skip to the next event.
